# Travail2

Simulateur de dépannage Active Directory : les seize scénarios du MVP
(niveaux N1 à N3), l'environnement simulé qu'ils partagent, leur format et un
validateur. Tout est dans `simulateur/` ; voir `simulateur/README.md`.

```sh
python3 simulateur/outils/valider.py --resume   # validation des scénarios
python3 simulateur/outils/test_valider.py       # tests du validateur
```
